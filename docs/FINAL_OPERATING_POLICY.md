# Final Operating Policy — ZTAD Mesh 4.2.0

1. Models propose; tools and protected platforms create evidence.
2. Benchmark/catalog quality is routing input, not authority.
3. Index the repository before model work and expand context rather than guess.
4. Use maximum useful parallelism; never parallelize overlapping writes.
5. Every writer uses a dedicated worktree and immutable scope.
6. Integrate into one candidate commit and pass machine checks before review.
7. Reclassify risk from the actual diff; risk may rise but not silently fall.
8. Never approve the candidate produced by the same run/session.
9. Never accept evidence absent from the registry or mismatched to task/SHA/diff/artifact/environment.
10. Every retry must demonstrate measurable progress or materially change strategy/context/resource.
11. Deny dangerous actions locally; continue unrelated safe runnable work globally.
12. Quarantine only the blocked node/task, preserve evidence, and reactivate only after a verified condition change.
13. Use frontier models for adjudication, sensitive review, takeover, closure, and release advice.
14. A model recommendation cannot override failed checks or authorize platform actions.
15. Merge, artifact promotion, deployment, canary, and rollback require verified target-platform controls.
16. Promote only the exact tested artifact and roll back on verified regression.
17. Do not claim full governed delivery from local files, hooks, or adapters alone.
