# Source Mapping

`references/MASTER_PLAN.md` is the normative ZTAD Mesh v4.3 plan. `references/ZTAD_1_SECURITY_FIRST_MASTER_PLAN.md` is retained as historical input only.

`traceability/requirements.csv` and `TRACEABILITY_MATRIX.md` map active controls to code, policy, schema, hook, test, skill, or external platform evidence. A mapping proves intended ownership, not target-platform enforcement. Every control marked external remains unverified until host acceptance supplies evidence.
